## Installation

```bash
# Install single plugin
opencode plugin install github.com/frs777/opencode-plugins/<plugin-name>

# Or download ZIP and install locally
opencode plugin install /path/to/plugin.zip
```

---

## Conversion Tools Used

- `gpt_to_oc` - ChatGPT/Codex → OpenCode V2
- `convert-full` - Full plugin conversion (manifest, tools, agents, mcp, skills)
- `convert-directory` - Unpacked directory → ZIP
- `convert-with-master-skill` - With auto-generated master skill
- `batch-convert` - Batch conversion
- `dry-run` - Preview without writing
- `validate-only` - Validation only
- `report-format` - Conversion reports

## Disclaimer

**Most plugins are conversions** from the OpenAI Codex plugin ecosystem. Original licenses were restored where possible from:
- Original Codex plugin cache (`~/.codex/plugins/cache/openai-curated-remote/`)

**4 plugins have restrictive licenses** (not open source): empire-llm-codex, mcp-boundary, plugin-creator-plus, servotab.
